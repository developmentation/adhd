Live picture

Builder works the chain. Anti-Drift watches.

builder · llm anti-drift · agent + evals

Rows are features in the application. Columns are the fourteen chain links. The Builder LLM edits cells fast and propagates a couple of hops. Every five turns, the Anti-Drift agent sweeps the board, reads the eval evidence, validates against the code, and drops tickets where the chain is weakening. Anti-Drift never edits application code.

Workflow

Code freeze and burn down

builder cadence observer pause

Observers add tickets while the Builder writes code. Once the queue hits the freeze threshold, the Builder stops shipping new code and drains the backlog. The observers stand down for the duration of the freeze, otherwise each fix would risk triggering a fresh ticket and the queue would never empty. When the queue clears, observers re-arm and the Builder resumes.
